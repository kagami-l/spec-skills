## How to read

- Every open row is for the human to read at Gate 2 and decide at their own pace: `Options` lists the choices, `Recommended` names the one this extraction suggests and why. Gate 2 judges the tree; no row has to be decided for the tree to pass.
- No row changes the tree or the code today: the packages specify the behavior as the code performs it, and an option that would change either is a later intent.
- A suspected bug offers two options, a later intent that fixes it or acceptance of the behavior as intended, and `Recommended` records the apparent intent.
- Row numbers are stable, since the ledgers and `plan.md` cite them; a merged row keeps the lower number and names the one it absorbed.
- A row that cannot be settled from this repository ends its `Observation` with **Outside evidence:** and names what is needed.
- Rows settled at Gate 1, at calibration, or during the loop move to the second table with the decision taken.
